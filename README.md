# agent-board

> This text was generated by an LLM ([how cgwalters uses LLMs](https://github.com/cgwalters/cgwalters#llms)). cgwalters has not reviewed it yet.

agent-board coordinates coding agents through a project board, independent of
any one forge: the board and its issues hold the work, agent-board decides what
job each issue should get, starts it once through a pluggable dispatcher, and
follows the pull requests that come back. GitHub is fully supported, Forgejo
boards are read-only, and GitLab is not supported yet.

**Documentation: <https://cgwalters-forge.github.io/agent-board/>**, built from
[`docs/`](docs/) and [`site/`](site/).

## Install

    cargo install --locked --git https://github.com/cgwalters-forge/agent-board agent-board

Then follow [setup](docs/setup.md) to try it offline and connect a board.
